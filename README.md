# Cell-wise detectability audit

Code and data for auditing a verification layer over stochastic discrete-event
simulation models. The unit of analysis is a **cell**: (template, judge,
observable, error class). The repository holds the simulation kernel, the judge
implementations, the task definitions, the injected artifacts and the per-cell
result matrices.

## Environment

Python 3.13.5 was used; the only third-party requirement is `numpy`. `simpy` is
needed by `pilot_c6/pilot.py` and by nothing else. Set `PYTHONIOENCODING=utf-8`
before long runs. Scripts resolve their inputs relative to `__file__`, so run
them from the repository root.

## Drivers

| Command | What it does |
|---|---|
| `python bench_v1/exp_2026-10-19/full64/run_summary_full64.py` | labels all 1,348 artifacts against the 83 thresholds and writes the per-category totals and the task-cluster bounds |
| `python bench_v1/exp_2026-10-19/full64/run_undetect_full64.py` | replays the theorem layer over the full matrix and lists every cell whose measured verdict disagrees with its prediction |
| `python bench_v1/build_tables_v2.py` | rebuilds the threshold table from the reference judgements |
| `python bench_v1/PIK_FULL64.py` | computes the blocking probability of each weak cell from its task parameters (Erlang loss formula, independent of the simulation) |
| `python bench_v1/_s3_kill/killtest.py` | kills and restarts the matrix driver on a small shard and compares the resumed output with an uninterrupted baseline (about six minutes; it terminates its own child processes) |
| `python bench_v1/exp_scaling/STRONG_SCALING.py` | re-times a fixed workload at a given worker count; the summary CSV in the same directory holds the measured runs |
| `python paper_figs/make_figs.py` | redraws the figures from the per-cell matrices; it exits if the number of plotted points differs from the matrix |
| `cd bench_v1/exp_2026-10-19/external && python run_external.py` | regenerates the held-out matrix; set `EXT_MAT_CSV` to the shard to write |
| `python bench_v1/criteria.py` | runs the judge self-checks |
| `python bench_v1/selfcheck_all.py` | runs all package self-checks |
| `python bench_v1/neg_test_selfcheck.py` | runs each gate against a planted defect; every gate must fail once |
| `python VERIFY_repro_package.py` | recomputes every sha256 in `MANIFEST.csv` and reports missing, changed, extra or leaked files |

## Reading the outputs

1. Denominators are nested: declared, then artifacts whose injected mechanism
   actually executed (IDLE), then artifacts with at least one judgeable cell,
   then definition collapses removed.
2. "IDLE" is used for three different objects: predictions in the theorem layer,
   artifacts in the artifact-level table, and cells in the sweep. They are not
   interchangeable.
3. Rates are reported per artifact and per task cluster; the second is the
   pessimistic bound for a new task from the same template.
4. Whether an artifact is IDLE is decided by the mechanism counter of its own
   error class, not by a union of counters.
5. J0 checks that a self-reported unit is self-consistent; it does not check that
   the unit is correct. Cross-checks against the invocation parameters are done by
   J0e.
6. A "weak" artifact counts as detected when any (judge, observable) cell fires.

## Notes

- Reports written by the scripts (`.md`) are generated, not versioned.
- Logs, downloaded papers and local working notes are not part of the repository.
- `bench_v1/coverage_gap.py` reads two generated reports; run
